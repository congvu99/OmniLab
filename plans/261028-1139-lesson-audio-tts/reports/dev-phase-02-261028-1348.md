## Lệch / quyết định nhỏ

- Lỗi tìm ra khi build: `tai-chinh/khoi-dong/vi-sao-hoc` có heading setext chứa hard break (`\` cuối dòng). `mdast-util-to-string` dán hai dòng liền nhau còn Astro giữ `\n`, nên bị `heading mismatch`. Sửa bằng `headingPlainText` theo đúng quy tắc của Astro; có test riêng.
- Dấu chấm cuối đoạn: ngoài chữ và số, cũng thêm khi đoạn kết thúc bằng `)`, `]`, dấu ngoặc kép hoặc `%`, để giọng đọc ngắt giữa các đoạn (heading kiểu "… (Cache)" rất phổ biến). Mở rộng nhỏ so với bảng quy tắc.
- Ô bảng: bỏ dấu `.;:,` ở cuối giá trị để không ra "x.; y".
- Kiểm "không chứa `|`" trong test kho được nới thành "không có hai dấu `|`": `web-crawler` có inline code `sort | unique` hợp lệ (quy tắc: inline code đọc nguyên chữ). Kiểm thẻ JSX/HTML dùng regex thẻ thay cho mọi dấu `<`, vì `database` có inline code `ColumnFamily<RowKey, …>`.
- Test được viết cùng lúc với code chứ không chạy đỏ trước; mỗi dòng của bảng quy tắc đều có test.
